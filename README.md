# ONE DESK · 경영지원 통합 플랫폼

경영지원(총무·회계·인사) 실무 경험을 바탕으로 기획하고, **HTML5 · CSS3 · Vanilla JavaScript**만으로 구현한
사내 경영지원 통합 웹 애플리케이션입니다. 서버·프레임워크 없이 브라우저 `localStorage`만으로 동작하는
정적 웹앱이며, GitHub Pages로 배포되어 있습니다.

**🔗 Live Demo:** _(GitHub Pages 배포 후 링크 추가)_

---

## 기획 배경

경영지원 직무(회계·총무)로 일하며 반복적으로 느꼈던 실무 불편함 — 지출결의서의 수기 합산, 예산 초과 여부를
매번 눈으로 확인해야 하는 점, 적격증빙 수취 여부를 개별적으로 챙겨야 하는 점, 연차 일수를 손으로 계산하는 점 —
을 하나의 대시보드에서 해결하는 것을 목표로 기획했습니다. 실무 지식(전자결재 결재선 규정, 적격증빙 기준,
정액법 감가상각 등)을 화면 설계에 직접 반영한 점이 이 프로젝트의 핵심입니다.

## 주요 기능

| 카테고리 | 핵심 기능 |
|---|---|
| **대시보드** | 이번 달 수입/지출/순이익 KPI, D-Day 정산 마감 타이머(브라우저 알림 지원), 오늘 출근 현황, 결재 대기 문서 요약 |
| **인사관리 (HRM)** | 직원 CRUD, 근속연수 자동 계산, 근로기준법 기준 연차 자동 계산(1년 미만 개근월/1년 이상 가산), 출근 상태 토글 |
| **전자결재** | 지출결의서 작성 시 공급가액·부가세(10%)·합계 자동 계산, **금액 구간별 다단계 결재선 자동 판단**(30만원 이하 팀장 전결 → 100만원 이하 팀장·본부장 → 초과 시 대표이사까지), 승인 시 회계 장부 자동 반영. **휴가신청서**는 신청 시 잔여 연차를 미리 보여주고, 최종 승인되면 인사관리의 사용 연차가 자동 차감됨 |
| **회계·지출증빙** | 수입/지출 CRUD, 월별 카테고리 예산 게이지 바(80%/100% 경고), **영수증 이미지 첨부·미리보기**(자동 축소 저장), 적격증빙 체크리스트(3만 원 초과 건 세금계산서 수취 여부 판정), CSV(엑셀) 다운로드 |
| **고객·영업관리 (CRM)** | 리드→상담→제안→계약 파이프라인 칸반, 단계별 이동, 파이프라인/계약 금액 집계 |
| **재고·자산관리** | 자산 CRUD, **정액법/정률법 감가상각 선택 계산**, 안전재고 이하 품목 경고 |
| **데이터 백업/복구** | 서버가 없는 정적 사이트의 한계를 보완하기 위해 전체 데이터를 JSON으로 백업/복구 |

## 기술 스택

- **HTML5 / CSS3 / JavaScript (ES6+, 프레임워크 없음)**
- 데이터 저장: `localStorage` (모듈별 상태를 하나의 JSON으로 통합 관리)
- 배포: GitHub Pages
- 폰트: Pretendard

## 폴더 구조

```
biz-suite/
├─ index.html            # 사이드바 + 콘텐츠 영역 (탭 전환형 SPA)
├─ css/
│  └─ styles.css         # 디자인 시스템 (컬러 토큰, 카드, 테이블, 게이지, 칸반, 모달)
└─ js/
   ├─ storage.js         # localStorage 저장/로드, JSON 백업·복구
   ├─ seed.js             # 최초 실행 시 예시 데이터
   ├─ ui.js               # 포맷터, 토스트, 모달 등 공용 유틸
   ├─ app.js              # 라우팅 및 초기화
   ├─ dashboard.js
   ├─ hrm.js
   ├─ approval.js
   ├─ accounting.js
   ├─ crm.js
   ├─ assets.js
   └─ settings.js
```

각 업무 모듈은 `Views.<key> = { title, subtitle, render(el) }` 형태로 독립 등록되며,
`app.js`가 사이드바 클릭에 따라 해당 모듈만 렌더링합니다. 모든 데이터는 하나의 `STATE` 객체로 관리되고,
변경 시 `persist()`를 호출해 `localStorage`에 즉시 저장됩니다.

## 실행 방법

별도 빌드 과정이 필요 없습니다. `index.html`을 브라우저로 열거나, 로컬 서버로 실행하세요.

```bash
# 예시: Python 내장 서버
python3 -m http.server 8080
# 이후 http://localhost:8080 접속
```
